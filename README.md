# Corrige Fácil

Aplicativo gratuito para configurar gabaritos, fotografar folhas de respostas e calcular notas diretamente no navegador. As fotos são processadas no próprio aparelho.

## Usar o aplicativo

- [Versão no GitHub Pages](https://igorgpaula.github.io/corrige-facil/)
- [Versão no OpenAI Sites](https://corrige-facil-provas.gdmseeds-whe-7678.chatgpt.site/)

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

O site é publicado automaticamente no GitHub Pages quando uma alteração é enviada para a branch `main`.
